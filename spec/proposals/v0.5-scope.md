# v0.5 — Scope Lock (2026-05-17)

**Theme: efficiency, observability, and submission.**

v0.5 is the cut where Codec proves it stays honest at scale, makes its energy + market story formally defensible, and graduates from "Quasarke's open protocol" to a citable, externally-referenced piece of inference infrastructure.

All v0.5 changes are **wire-additive over v0.4** per the [Versioning Policy](../versions/v0.4.md#versioning-policy). A v0.4 client speaking to a v0.5 server sees v0.4 frames byte-for-byte. Anything that would force a breaking change escalates to v1.0 and stops the cut.

---

## Explicitly out of scope (deferred to v0.6)

- **Security pass** — the 10-item threat model + MUSTs from the original v0.5 plan (client-claimed version trust, leaf-mode `_meta` integrity, KV-cache poisoning, latent buffer overflows, well-known cache poisoning, sentinel token spoofing, 426 fingerprinting, version-policy replay, safety-policy descriptor replay, mcp-leaf truncation, CRLF injection on `Codec-Required-Features`)
- **Header efficiency** — OPTIONS preflight + persistent `Codec-Session` token, wire-overhead proposal §1-§4 (truncated hashes, drop-advisory-on-2xx, etc.), T2.7 capability bitmap (`Codec-Caps` / `Codec-Caps-Required` replacing the `Codec-Client-Version` / `Codec-Required-Features` string forms)
- **HTTP/2 cluster** (both grouped with v0.6 header efficiency — all want persistent connection state):
  - **v0.2 OQ2 multi-stream multiplexing** (HTTP/2 push-style parallel streams in one connection, for speculative-decoding outputs). Carried forward unresolved through v0.3 and v0.4.
  - **HPACK-style header compression** for HTTP/1.1 fleets (the analog [`docs/WIRE_OVERHEAD_PROPOSAL.md`](../../docs/WIRE_OVERHEAD_PROPOSAL.md) cites HTTP/2's HPACK as needing a Codec-level companion for uvicorn-behind-nginx-proxy deployments). Pairs naturally with `Codec-Session`.
- **Language-tier compression** — [`v0.6-prompt-dialects.md`](v0.6-prompt-dialects.md), the "caveman / logographic mapping / compression-preferred prompting" group, and the [`COMPRESSIBLE_PROMPTS.md`](../../packages/bench/docs/COMPRESSIBLE_PROMPTS.md) companion patterns
- **v0.4 OQ1 SAFETY_VIOLATION frame type (0x07)** + v0.4 OQ3 MCP-leaf safety enforcement signaling — both security-adjacent

## v0.5 scope (locked)

### Engine-side efficiency (wire-additive, default-off)

| ID | Item | Effort | Source |
|---|---|---|---|
| **T1.4** | Server-side OpenAI bypass — `CODEC_OPENAI_BYPASS=1` env on **both sglang + vllm** forks. Engine emits a token-buffer view (numpy uint32 / torch tensor) straight to `codec_frame` encoder; `codec_frame` gains `Union[List[int], array.array, np.ndarray, bytes]` overload using msgspec array-native path. Byte-identical wire; ~25-40% codec-encode CPU saved per token at concurrency. | sglang + vllm, ~2 wks | [v0.5 plan T1.4](/home/willi/.claude/plans/ok-lets-start-a-valiant-bachman.md) |
| **T2.5** | Delta-varint stream encoding — new `stream_format: "msgpack-delta"` / `"protobuf-delta"` axis. Frame metadata carries `base_id`; bodies carry zigzag-varint deltas to last id of previous frame (stateless framing preserved). Opt-in only; ~10-15% pre-zstd wire reduction, ~3-5% post-zstd. | core + per-client, 1 wk | v0.5 plan T2.5 |
| **T3.8** | GPU-side latent quantization — `gpu_quantize: bool` flag on `LatentStreamEncoderOptions`. When True + input is `torch.Tensor` on GPU, quantize on-device with torch ops before `.cpu().numpy()`. Re-vendor in ComfyUI + diffusers forks. int4 path saves ~75% PCIe bytes on SDXL / video latents. | encoder + 2 forks, 1 wk | v0.5 plan T3.8 |

## Open questions inherited from earlier versions (status at v0.5 cut)

- **v0.2 OQ2 — Multi-stream multiplexing** (HTTP/2 push-style parallel streams for speculative-decoding outputs). Carried forward unresolved through v0.3 and v0.4. **Deferred to v0.6** alongside the persistent-session header-efficiency work — both want the same connection-state design.
- **v0.3 OQ — Pipeline registry governance** (latent pipeline list): No change in v0.5 unless a sixth pipeline lands. Still open.
- **v0.4 OQ1 — Dedicated `SAFETY_VIOLATION` frame type (0x07)**: deferred to v0.6 (security-bucket).
- **v0.4 OQ2 — Engine hidden-state hook for embedding-space classifiers**: still gated on an engine fork shipping a stable hidden-states callback (vLLM leading candidate). Out of scope for v0.5; tracked.
- **v0.4 OQ3 — MCP-leaf safety enforcement signaling**: deferred to v0.6.
- **v0.4 OQ4 — Token-ID list authoring tooling**: scoped INTO v0.5 as the `policies-enumerate` CLI subcommand.
- **HPACK / HTTP/1.1 header compression** (from `docs/WIRE_OVERHEAD_PROPOSAL.md`): not a formal OQ in any version doc, but a real outstanding design choice that the wire-overhead proposal flags. **Deferred to v0.6** with the rest of the header-efficiency cluster.
